# Fundación Beit Shalom - Sitio Web Institucional

## Descripción
Proyecto de maquetación y diseño web responsivo adaptado para la asignatura **Programación Orientada a Objetos** de la **Universidad Doctor Andrés Bello (UNAB)**.

## Información Académica
* **Institución**: Universidad Doctor Andrés Bello
* **Facultad**: Tecnología e Innovación
* **Carrera**: Ingeniería en Computación
* **Docente**: Ing. Balmore Montano
* **Tema**: Diseño Web Responsivo - Demo

## Tecnologías Utilizadas
* HTML5 / CSS3 / JavaScript
* Bootstrap 5 / jQuery
* VS Code + Live Server

## Estructura de Archivos Principal
* `index.html`: Página de Inicio
* `nosotros.html`: Historia, Misión y Visión
* `contacto.html`: Formulario, Ubicación y Teléfonos
* `assets/css/beit-shalom.css`: Estilos personalizadosff
